# Chermane Trades

Marketing site for Chermane Trades, built with Next.js (App Router) and TypeScript.

```bash
npm install
npm run dev
```

- `app/` — layout, page and global styles
- `components/` — page sections and client-side effects (preloader, countdown, signal chart, scroll reveals)
- `lib/data.ts` — copy for features, plans, reviews, FAQ and links
